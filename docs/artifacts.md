# Артефакты и очистка

| Путь | Содержимое | Что делать |
| --- | --- | --- |
| `target/` | Rust build-кэш, промежуточные файлы, тестовые контейнеры/PFX и бинарники | Воспроизводимая сборка очищается `cargo clean`; вложенные нестандартные тестовые папки отдельно удаляются после проверки. |
| `dist/` | Готовые архивы, SHA-256, распакованный комплект | Сохранить для запуска; не входит в Git. |
| `tools/` | Необязательные внешние исходники, OpenSSL provider | Не нужен обычному CLI; сохранить для воспроизведения interop. |
| `.idea/` | Настройки IDE | Не является build-кэшем; оставлен локально. |

Перед `cargo clean` скопируйте готовую программу в `dist/` с помощью упаковщика. После очистки запускайте бинарник из `dist/gost-sign-<версия>-<платформа>/`. `cargo clean` не удаляет `dist`, исходники и пользовательский Cargo registry. Тестовые контейнеры внутри `target` одноразовые; при необходимости заново создаются скриптом генерации фикстур.

PFX, P12, `*.key`, `*.000`, `.env`, `private/`, `target/`, `dist/`, локальные рабочие материалы и внешние исходники исключены из Git. Не помещайте рабочие ключи в проект. Упаковка копирует только разрешённые публичные файлы и не собирает каталог проекта целиком.

Каталог `private/` содержит только локальные материалы и не публикуется.
