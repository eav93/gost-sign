# Использование

## Установка

Архив содержит один бинарник, README, документацию, уведомления о лицензиях и `BUILD-INFO.txt`. Внешний SHA-256 относится к архиву. Выбирайте архитектуру своего компьютера: `x86_64` для Intel/AMD или `aarch64` для ARM64/Apple Silicon. Windows-архив — ZIP, Linux/macOS — TAR.GZ.

На macOS и Linux запустите `./gost-sign`, на Windows — `.\gost-sign.exe` в PowerShell. Windows также позволяет открыть `.exe` двойным щелчком. Запуск из терминала позволяет увидеть ошибки запуска. Это консольная программа с интерактивным меню, не графическое приложение.

Linux-сборки используют glibc Ubuntu 24.04 и системную `libpcsclite.so.1`; Alpine/musl не поддерживается этими архивами. На Ubuntu/Debian установите `libpcsclite1`; для токена также нужны `pcscd` и подходящий драйвер считывателя. macOS использует системный PCSC.framework, Windows — WinSCard. Драйвер конкретного токена устанавливается отдельно при необходимости. Наличие библиотеки PC/SC требуется и для запуска полной сборки при работе только с PFX; работающий демон нужен именно для карты.

Готовые архивы не подписаны сертификатом разработчика и не нотарифицированы Apple; macOS/Windows могут запросить подтверждение запуска. Не отключайте системную защиту целиком. Минимальные системные версии вне образов CI отдельно не проверены.

## Основной сценарий

1. Выберите «Перенести ключ и сертификат в PFX».
2. Укажите папку контейнера КриптоПро `.000` или подключённый Рутокен Lite.
3. Программа запросит исходный пароль контейнера, если защита обнаружена. PIN токена запрашивается только после отказа чтения из-за отсутствия авторизации.
4. После проверки пары ключ–сертификат выберите файл PFX и задайте новый непустой пароль дважды.
5. Для дальнейшей подписи выберите «Подписать документ», откройте PFX с новым паролем и укажите документ. По умолчанию подпись записывается рядом с документом, например `invoice.pdf.p7s`.

Исходный контейнер и документ не изменяются. Подпись отсоединённая: получателю нужны и исходный документ, и `.p7s`. Изменение хотя бы одного байта документа нарушает подпись. PFX храните вместе с резервной копией; пароль передавайте отдельно.

## Интерфейс

- После успеха, отмены или ошибки возвращается главное меню.
- `:назад` отменяет действие в любом обычном поле; при скрытом вводе пароля это обычные символы пароля.
- `Ctrl+C` завершает процесс. После EOF программа выходит, не повторяя меню бесконечно.
- Путь с пробелами вводится целиком; допускаются окружающие одинарные или двойные кавычки. Shell-подстановки `~`, `$HOME` и экранирование пробелов обратным слешем не выполняются: используйте полный путь из файлового менеджера.
- `Enter` принимает значение в квадратных скобках. Существующие файлы защищены от перезаписи, включая конкурентное создание файла.
- Пароли не принимаются через аргументы CLI или переменные окружения.
- `gost-sign --help` — справка, `gost-sign --version` — версия.

## Экспорт сертификата

Пункт 4 принимает PFX, папку контейнера, `header.key`, сертификат X.509 DER либо Рутокен Lite. При наличии нескольких сертификатов можно выбрать нужный. Результат — DER `.cer`, без закрытого ключа. PEM/P7B пока не поддерживаются. Из PFX сертификат извлекается после ввода пароля и проверки привязки ключа; для локального заголовка и токена это только чтение сертификата, без проверки MAC контейнера и доверия цепочке.

## Рутокен Lite

Поддержан профиль Lite 1010. При нескольких считывателях программа предлагает выбор; единственный выбирается автоматически. Каталог контейнера пока вводится вручную, по умолчанию `0a00`; автоматического поиска нет. Диапазон — `0a00–0aff`.

При переносе ключа выполняется одна попытка проверки пользовательского PIN, только если чтение вернуло статус `6982`. Неверный PIN не перебирается и не повторяется автоматически. После успешного входа права доступа сбрасываются по окончании чтения, в том числе при ошибке чтения. Экспорт только сертификата не отправляет PIN. Наличие этого пути в программе пока не означает подтверждённую работу на физическом устройстве.

## Если что-то не получилось

| Сообщение/ситуация | Действие |
| --- | --- |
| Файл уже существует | Выберите другое имя; программа не перезаписывает данные. |
| PFX не открывается | Проверьте пароль. Старый PFX КриптоПро с алгоритмом `.80` не поддерживается основным модулем; перенесите исходную папку `.000`. |
| Ключ не соответствует сертификату | Проверьте источник; несовпадающая пара не экспортируется и не подписывает. |
| Считыватель не найден | Проверьте подключение, драйвер и службу PC/SC. |
| Неверный PIN | Проверьте PIN, не повторяйте попытки наугад; у карты ограничен счётчик. |
| Неподдерживаемые параметры | Сейчас поддержаны ГОСТ 2012-256 TC26-A и CryptoPro-A/XchA/TC26-B, не все виды контейнеров. |
| Подпись не соответствует документу | Нужен исходный документ байт-в-байт и соответствующий `.p7s`. |
